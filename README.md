## 🌐 网页增强版 `flappy-bird-enhanced.html`

**双击文件用浏览器打开即可**，无需服务器、无需联网、无外部依赖（图形/音效全部代码生成）。

### 5 种游戏模式（模式选择菜单可切换，各自独立记录最佳分）

| 模式 | 特点 |
|------|------|
| 🐤 **经典** | 原汁原味，稳定难度，随分数缓慢加速 |
| 🍃 **禅意** | 宽间距、慢节奏，适合新手放松练习 |
| 🔥 **极速** | 越来越快，得分 ×2，红色夕阳主题 |
| 🌙 **夜航** | 视野受限，只有小鸟身边看得见（聚光灯效果），得分 ×1.5 |
| ⚡ **风暴** | 管道上下晃动 + 随机阵风（上升/下沉气流）+ 闪电，得分 ×1.8 |

### 更多玩法与 UI

- **金币系统**：飞行途中拾取金币，累计连击可额外加分；累计金币持久保存。
- **连击**：连续吃币触发连击倍数与飘字特效。
- **奖牌结算**：🥉铜 / 🥈银 / 🥇金 / 🏅大师，破纪录有庆祝动画。
- **动态难度**：随分数收窄间距、提速（禅意模式除外）。
- **视听效果**：视差远山/云层、昼夜/暴风多主题天空、粒子爆炸、屏幕震动、连击飘字、Web Audio 合成音效（可 `M` 静音）。
- **响应式**：按设备像素比自适应缩放，桌面与手机触屏均可玩。

### 操作

| 按键 | 作用 |
|------|------|
| `空格` / `↑` / `W` / 点击 / 触屏 | 拍翅膀（起飞） |
| `↑` `↓` / 点击卡片 | 菜单中选择模式 |
| `空格` / `Enter` | 确认 / 重开 |
| `P` | 暂停 / 继续 |
| `Esc` | 返回模式菜单 |
| `M` | 静音开关 |

进度（各模式最佳分、累计金币、静音设置）通过 `localStorage` 持久化。

## 🖥️ Qt 桌面版

Qt Widgets + C++ 的原生桌面版，已与网页版对齐并**额外新增皮肤商店与激光门**：

- **6 种游戏模式**：🐤 经典 / 🍃 禅意 / 🔥 极速 / 🌙 夜航（聚光灯视野）/ ⛈ 风暴（管道晃动+阵风+闪电）/ ⚡ **激光**。
- **⚡ 移动激光门**（新）：激光模式的障碍是上下移动的激光门 —— 发光横梁 + 红色发射器，激光会周期性闪灭（灭时可穿过），抓准间隙通过。
- **🛒 皮肤商店**（新）：8 款小鸟皮肤（含霓虹发光、彩虹变色），用游玩收集的金币购买并装备；拥有/选中通过 `QSettings` 持久化。
- **金币 + 连击**：飞行途中拾取金币，连击加分并飘字，累计金币作为商店货币。
- **精致 UI**：模式选择菜单、视差远山/云层、多主题渐变天空、粒子爆炸、屏幕震动、暂停、结算奖牌与新纪录庆祝。
- **窗口可缩放**：内部 480×720 逻辑画布等比缩放，拉窗口不变形。

> 无外部资源依赖，图形全部由 `QPainter` 代码绘制（此版本不含音效）。

## 用 Qt Creator 打开

1. 安装 Qt（5.15 或 6.x 均可，含 MinGW 或 MSVC 编译套件）。
2. Qt Creator → **文件 → 打开文件或项目** → 选择 `FlappyBird.pro`。
3. 选择一个 Kit（如 `Desktop Qt 6.x MinGW 64-bit`）→ **Configure Project**。
4. 点击左下角绿色 **▶ Run** 即可。

## 命令行编译（可选）

```bash
qmake FlappyBird.pro
mingw32-make    # 或 nmake / make
./FlappyBird
```

## 操作

| 按键 | 作用 |
|------|------|
| `空格` / `↑` / `W` / 鼠标左键 | 拍翅膀（起飞） |
| `↑` `↓` / 点击卡片 | 菜单中选择模式 |
| `回车` / `空格` | 确认 / 重开 |
| `B` / 点击「皮肤商店」 | 打开商店 |
| `P` | 暂停 / 继续 |
| `Esc` | 返回菜单（在菜单中再按则退出） |

各模式最佳分、累计金币、已购/已装备皮肤均通过 `QSettings` 持久化（注册表 / ini）。

